- 功能清單（ADR-0007）：
  - **`NcuNewsAdapter`**：以 `@registry.register("ncu_news")` 註冊，擷取新聞網的三個列表：
    - 中大新聞 `headlines.php`（`div.release-list-card` 版型）；
    - 焦點新聞 `focus-news.php`、學術新聞 `academic-news.php`（`a.box-card` 版型）。
  - **列表解析**：兩種版型共用同一規則。卡片連結指向 `headlines_content.php?H_ID=<id>`，連結內有標題 `h3`、分類 `.tab-box`、日期 `.date-box`。
    - 沒有標題的連結（選單、分頁、輪播圖）、他站連結都略過；
    - 網址正規化為 `https://ncusec.ncu.edu.tw/news/headlines_content.php?H_ID=<id>`，相對路徑與根目錄路徑都會得到同一個網址；
    - 找不到任何新聞卡片時拋出 `LayoutChangedError`。
  - **內頁解析**：`section.main-detail-box` 中的 `h3.main-title`（必要）、「發布日期：YYYY-MM-DD」、`.main-detail-content-box`（保留 HTML，不含瀏覽人次與分享按鈕）。
    - 缺內頁區塊或標題時拋出 `LayoutChangedError`；
    - 沒有文字內文時以標題作為內容（`text/plain`）；
    - 內頁沒有日期時改用列表頁日期；只有日期，視為台北時間當日 00:00，存成 UTC。
  - **跨列表去重**：`H_ID` 是三個列表共用的流水號，作為 `external_id`。同一篇出現在多個列表只抓一次內頁、只產出一筆。
  - **分類**：取各列表標籤的聯集，放在 Adapter 的 `categories` 屬性（external_id → 分類集合）。`RawItem` 與資料庫目前沒有分類欄位，**不會寫入資料庫**（見已知限制）。
  - **cursor**：已擷取的最大 `H_ID`；每輪由舊到新最多 `max_items` 篇（預設 20），cursor 不會倒退。
  - **只讀第一頁**：不跟隨分頁、不回溯約 2,387 筆歷史新聞。
  - **擷取原則**（沿用 P1-T03）：
    - 每個網域每輪檢查一次 robots.txt；網站的 robots.txt 會 302 轉址到一般 HTML 頁面，解析後沒有規則，視為允許；
    - 同網域請求間隔 ≥ 5 秒（共用 `HostRateLimiter`）、專案 User-Agent；
    - 錯誤分類：5xx、408、425、429、逾時、連線失敗可重試；其他 4xx、robots 禁止、頁面過大不可重試；內頁 404、轉址到他站、robots 禁止則略過並計入 `last_skipped`。
  - **設定檔**：`config/sources.yaml` 新增 `ncu-news`，類型 `ncu_news`，三個列表網址，依來源盤點建議**每 6 小時**擷取一次。

## 已知限制

1. **分類沒有寫入資料庫**：`RawItem` 是 `extra="forbid"`，`source_items` 也沒有分類或 metadata 欄位，所以分類只存在 Adapter 的 `categories` 屬性，一輪結束就沒了。要保留下來，需要擴充 `RawItem` 與 `store.py`，並新增 migration，超出本任務範圍。
2. **與 RPage Adapter 有重複程式**：robots.txt 檢查、串流讀取與錯誤分類（`_allowed`、`_get`）和 `ncu_announcements.py` 幾乎相同。為了不修改 P1-T03 的檔案，本任務複製了這段程式；之後可以抽到 `app/ingestion/http.py` 共用。
3. **偶發的連線中斷**：真實驗證時第一次請求遇到伺服器中斷連線，重跑就成功。這會被當成可重試錯誤，交給 P1-T07 的重試與死信處理；P1-T10 的穩定運行報告會顯示實際頻率。
4. **只看各列表第一頁**：首次擷取不回溯歷史；6 小時內若有超過一頁（12 則）的新新聞，超出的部分不會被抓到。新聞網目前約每天 1–2 則，風險很低。
5. **新聞事件性低**：內容以研究成果、活動報導為主；停課、災害示警仍以校園公告與 `cwa-alerts` 為主。
6. **授權**：校方網站頁尾為「版權所有 All rights reserved」，沒有明示再利用授權；正式導入前應取得秘書室書面同意（ADR-0007 已記錄）。

3. 沒有 migration，不需要資料庫回退；已寫入的 `ncu-news` 項目可保留或依來源刪除（刪除前需使用者同意）。
