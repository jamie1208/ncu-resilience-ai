## 已知限制

- Session 只有絕對有效期（12 小時），沒有閒置逾時。
- 鎖定只針對已存在的帳號計數；不存在的帳號名稱不計次（個人版只有一個帳號，影響小）。沒有 IP 層限流。
- Secure cookie：Chrome／Firefox 視 `http://localhost` 為安全來源可用；Safari 在 http 下可能不送出，需改 HTTPS（P5 部署處理）。
- 過期、撤銷的 `user_sessions` 列不會自動清除（資料量極小，之後可加清理工作）。
- `REPORTS_READ_INTERNAL` 權限暫留（ADR-0008 已無投稿，但移除會牽動既有測試與稽核規則，留待相關任務）。
