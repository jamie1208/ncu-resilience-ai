## 已知限制

- WEB_PORT 原預設 8080 與使用者本機的 Java 程式衝突，已依使用者決定改為 8088。**使用者本機既有的 `.env` 是在改預設前由舊範例複製的，仍是 `WEB_PORT=8080`**，需要使用者自行改為 8088（AI 不讀寫 `.env`）。
- 開發環境沒有熱重載：api 與 web 都使用建置後的映像，改了程式碼要重新 `make up`。日常開發仍可在本機用 `uv run uvicorn --reload` 和 `npm run dev`。
- Docker healthcheck 每 10 秒呼叫一次 health，會在 api 日誌中產生對應的請求紀錄，日誌偏多。
- health 尚未檢查 db／redis 連線（P0-T05 起加入）。
- worker 在 P1-T07 之前無法啟動。
- 本機用 AI 的 shell 執行 `make test` 時需要 PATH 含 `~/.local/bin`（uv 安裝位置）。
