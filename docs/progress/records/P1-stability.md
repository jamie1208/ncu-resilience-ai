### 原因

- **不是程式問題，而是本機網路中斷**：
  - 04:13–10:43 之間，所有連網來源都是 `ConnectError`，連氣象署 API 也一樣；

- **電腦沒有睡眠**：`caffeinate` 持續了 14 小時。

### 後續處理（2026-10-19，使用者決定）

1. **自動停用不再計入可重試的失敗**：修改 `backend/app/ingestion/health.py`。只有不可重試的失敗（版型改變、4xx、設定錯誤、其他例外）才計入「連續 5 次失敗停用」；連線失敗、逾時、5xx（`SourceUnavailableError`）在判斷中略過，仍然寫入死信、計入失敗率。之後網路中斷時，來源不會被停用，網路恢復後就自動回到正常。
2. **重新啟用 8 個被停用的來源**：cwa-alerts、ncu-aa、ncu-announcements、ncu-cc、ncu-epsc、ncu-lib、ncu-osa-life、ncu-sec。重建 worker 後，`python -m app.worker.tasks.ingest --source all --once` 顯示 11 個來源全部 succeeded。
