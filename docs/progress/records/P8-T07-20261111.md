## 已知限制

- 目前唯一的管道是通知中心 inbox，送出不會失敗；重試在有外部管道（例如 email）時才實際發揮作用。e2e 以種子腳本中的替身管道模擬失敗，畫面上只能驗證通知只出現一次。
- 至少一次：送出成功但 commit 前 worker 當機，下次會再送一次。
- 重試次數與間隔是 `delivery.py` 的常數，不在設定檔。
- 規格 v1.1 的 A10 寫「不自動重試」，本任務依 P8 計畫取代；待 P8-T12 寫入 spec v1.2。
- 放棄重試的列仍為 `failed`（`next_attempt_at` 為 NULL），後台目前不顯示遞送狀態。
