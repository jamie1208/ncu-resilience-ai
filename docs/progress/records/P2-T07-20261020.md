## 已知限制

1. **模型輸出不穩定**：第 4 輪 30/30，接著錄製時只有 27/30；修改後連續兩輪 30/30，但仍可能有變異。CI 用的是錄製回應，不受影響；正式執行時，Runner 會重試，仍失敗就 abstain。
2. **原句比對失敗會造成重送**：第 2 輪有 3 次、失敗錄製時有 4 次。Runner 只在最終失敗時記錄問題代碼，看不到中途的原因；重送時也沒有把錯誤回饋給模型（P2-T04 已知限制 3）。
3. **時間換算由模型負責**：正確率只比對開始日期，不比對時間與結束日期；年份推定、跨年等規則還沒有案例覆蓋。
4. **案例全部是自行撰寫的**：真實資料的寫法更多樣，例如公告中的表格、多個日期。
5. **地點標準名稱清單不完整**：只列出公告與貼文中出現過的地點。
