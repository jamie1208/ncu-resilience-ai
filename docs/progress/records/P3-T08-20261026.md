- 撤回／過期不另外送「撤回通知」；通知中心直接顯示狀態與撤回原因。
- 事件狀態 monitoring 視為 unverified（一般安全提醒），因為查證結論沒有另存欄位。
- 管線與 verify 在同一交易中遞送；外部管道（Email）上線時應改為 commit 後由 worker 送出。
