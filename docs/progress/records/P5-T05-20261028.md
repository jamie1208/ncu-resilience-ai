- 功能清單：
  - `backup.sh`：`pg_dump -Fc` 備份本機 compose 的資料庫；以一個 `REPEATABLE READ READ ONLY` 交易匯出快照，dump 與各表筆數用同一快照，服務不停機也一致；產生 `.dump`、`.counts.tsv`、`.sha256`；輸出到 repo 外的 `NCU_BACKUP_DIR`（預設 `~/ncu-resilience-backups`），目錄 700、檔案 600；備份後以 `pg_restore --list` 確認可讀；不刪除舊備份。
  - `restore.sh --target local`：核對 SHA-256 → 重建資料庫 → `pg_restore --single-transaction --exit-on-error --no-owner` → 逐表比對筆數，不一致以 1 結束。預設還原到演練庫 `<POSTGRES_DB>_restore_drill`，通過後刪除（`--keep` 保留）；`--file` 指定備份、`--database` 指定目標；目標已存在需 `--replace`；目標是正式資料庫時另需終端機互動輸入資料庫名稱，並在還原前停止、結束時重新啟動 api／worker／beat。資料庫名稱只允許 `[a-z_][a-z0-9_]*`，拒絕系統資料庫。
  - 帳密只在 db 容器內由環境變數取得，腳本不讀 `.env` 內容也不輸出密碼。
  - 相容 macOS 內建 bash 3.2（沒有 coproc，用 FIFO 保持交易工作階段；含全形字元的字串一律用 `${變數}`）。

- 還原到正式資料庫的路徑（`--database ncu_resilience --replace`）未實際演練：會取代現有資料，需使用者本人在終端機執行。它與演練共用同一段還原與驗證程式。

- 只支援 `--target local`。
