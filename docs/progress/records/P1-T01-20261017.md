- 功能清單：
  - `SourceAdapter` Protocol（runtime_checkable）：
    - `code` 屬性；
    - `async fetch_since(cursor) -> list[RawItem]`（計畫指定）；
    - **另加 `next_cursor(items, previous)`**：計畫只寫了 `fetch_since`，但排程器需要知道下一輪的 cursor 才能做到增量擷取（規格 F01）。cursor 是 Adapter 自訂的不透明字串。
  - 錯誤類型：`AdapterError` 與 `retryable` 旗標。
    - `SourceUnavailableError` 可重試（逾時、5xx）；
    - `LayoutChangedError` 不可重試（版型改變，規格 §16；P1-T03 會使用）。
  - `RawItem`（pydantic frozen model）：
    - url 必須是 http(s) 絕對網址；
    - source_code、content 不可為空白；
    - content_type 只能是 text/plain 或 text/html；
    - 時間必須帶時區，並轉為 UTC；
    - 建立後不可修改，不接受未定義的欄位。
    - docstring 註明內容不可信，送進模型前要以 `<untrusted_source>` 包裹。
  - `SourceConfig`：code、type、access_policy、enabled、唯讀的 options。access_policy 建立時轉為 `AccessPolicy` 列舉，資料庫讀出的字串也能用，無效值會被拒絕。
  - `AccessPolicy`：approved、pending、deferred、rejected，對應來源盤點的核准、待決定、暫緩、不核准。
  - `SourceRegistry`：
    - 以 `@registry.register("<type>")` 註冊，重複註冊會拒絕；`types()` 列出已註冊類型；
    - `create(config)` **只為核准且啟用的來源建立 Adapter**，未核准或停用時拋出 `SourceNotApprovedError`，對應 P0-T09 與閘門 G1-1；
    - 應用程式共用 `registry` 實例。

## API 範例

```python
from app.ingestion.registry import registry
from app.ingestion.types import SourceConfig

@registry.register("rss")
class RssAdapter: ...

adapter = registry.create(SourceConfig(code="cwa-alerts", type="rss",
                                       access_policy="approved", enabled=True,
                                       options={"url": "https://..."}))
items = await adapter.fetch_since(cursor)
cursor = adapter.next_cursor(items, cursor)
```

## 已知限制

- **Adapter 的連線設定（例如 feed URL、列表頁網址）從哪裡來還沒決定**：`sources` 表（規格 §9）沒有 url 或設定欄位，`SourceConfig.options` 目前只是介面。需要在 P1-T02、P1-T03 之前決定，見下方。

- registry 的 `create` 只檢查 access_policy 和 enabled；擷取頻率（poll_interval）由排程器（P1-T07）處理。
