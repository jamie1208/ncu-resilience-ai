## 已知限制

1. **標記資料的類別不平衡**：
   - 目前 none 94、facility 11、weather 6；security、traffic、health、fire、academic、infosec 都是 0 筆；
   - 高風險只有 2 筆，幾乎沒有謠言或來源衝突的樣本；
   - 開發 S01、S03 前要補標；規格 §14.1 建議擴充到 300–500 筆。
2. **第二批 46 筆是 AI 預標、使用者逐列確認的**，可能受預標影響；評測時要註明。
3. **G1-2 是豁免通過**（ADR-0012），連續性沒有完整驗證。
4. **Facebook 的識別方式還在試行**（ADR-0011，內文雜湊），要在試行一週後評估。排程在網路正常的情況下能不能寫檔，也還沒有驗證。
5. **tracker 的閘門指令依賴 `uv` 在 PATH 中**：在沒有 `~/.local/bin` 的環境中，G1-3 會誤報失敗。
6. **總務處來源暫緩**，目前沒有停水停電的主要官方來源。
