- frontmatter：`name` 等於資料夾名稱去掉開頭底線，且為小寫連字號、≤ 64 字元；description 為 1～1024 字元；version 是字串 semver；schema_version 是字串整數；

## 已知限制

1. **還沒有正式的靜態驗證**：目前只用暫時性腳本核對，正式的 validate_skill 與 CI 檢查在 P2-T02。
2. **錄製回應是手寫的**：模板的錄製回應全部符合 expected，所以只能驗證框架流程，不能代表模型的實際表現。產品 Skill 必須用真實模型錄製。
3. **介面還沒有實作驗證**：case、`must_not` 與錄製回應格式是 P2-T03（fake provider）與 P2-T05（評測）要遵守的介面；實作時如果發現不足，要修改 skill-standard 並升模板版本。
4. **輸入 schema 的共同部分只規定了 `evidence`**：S04、S06 等需要其他輸入的 Skill，各自擴充。
5. **strict 子集依據的是目前對 OpenAI Structured Outputs 的理解**：P2-T03 實際呼叫時要再確認（例如 `format: date-time` 只用在輸入 schema，輸出 schema 沒有使用）。
