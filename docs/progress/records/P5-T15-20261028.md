## 已知限制

- Quick Tunnel 網址每次啟動都會換，沒有可用性保證；電腦關機／睡眠時公開網站停止。
- 隔離靠閘道白名單：管理端與公開 API 在同一個 api 行程，新增公開頁面路徑時需同步更新 `nginx-public.conf` 與 `tunnel.sh check`。
- `make up-local` 不含通道覆寫檔，執行後 api 會回到不信任轉送標頭；通道在用時需再執行 `tunnel.sh gateway`（runbook 已註明）。
- `FORWARDED_ALLOW_IPS="*"` 讓 api 信任所有來源的 `X-Forwarded-For`；api 只綁 127.0.0.1，外部只能經閘道（閘道一律覆寫），本機使用者可偽造，影響僅限限速。
- Cloudflare 本身可見連線資訊，不在本系統控制範圍。
- tunnel 容器為 `restart: unless-stopped`：上線中重開機會自動恢復對外（網址會換）。

## 回退步驟
