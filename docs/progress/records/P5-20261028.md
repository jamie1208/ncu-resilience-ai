## 已知限制

- G4-7（真實資料連續 3 天產生事件）尚未通過；P5 是在使用者同意下超前開始（2026-10-27）。
- Quick Tunnel 網址每次啟動都會換，沒有可用性保證；電腦關機／睡眠時公開網站停止。
- 管理端與公開 API 在同一個 api 行程，對外隔離靠公開閘道白名單；新增公開頁面需同步更新 `nginx-public.conf` 與 `tunnel.sh check`。公開網站與管理端仍是同一個 SPA bundle。
- 限速為行程內記憶體計數，重啟即重置。
- 疑似指控只用關鍵字規則，會誤擋官方公告；沒有人工核可後公開的路徑。
- 匿名投稿資料沒有保存期限。
- Docker Desktop「登入時自動啟動」需使用者自行打開；真正重新開機驗證尚未做。
- 公開 API 的瀏覽器快取最多殘留 30 秒；事件被判為不實時自動撤下最晚約 1 分鐘。
- 檢查通道對外的 `tunnel.sh check` 是從本機經公開網址發出，不是從另一個網路。
