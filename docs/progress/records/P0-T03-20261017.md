## 已知限制

- 沒有在實際瀏覽器做視覺檢查，包括 375px 寬度有沒有水平捲動、中文字體實際的顯示效果。這兩項目前只靠程式碼審閱（`overflow-x-hidden`、裝飾元素 `hidden lg:block`、按鈕 `w-full sm:w-auto`）與建置後的 CSS 確認。Playwright 屬 P3 以後的任務。
- 首頁按鈕是停用狀態的佔位（「即將推出」）；事件列表與詳細頁在 P3-T04。
- JS bundle 388.8 kB（gzip 124 kB），其中 Framer Motion 佔了不少；後台目前也會載入它。ADR-0003 允許必要時改用 lazy import 拆分。
- Google Fonts 從外部載入，需要網路；字體的 `display=swap` 會造成短暫的字體替換。
- `buttonVariants` 沒有匯出，因為 react-refresh 的 lint 規則限制元件檔只能匯出元件；之後若有需要，再拆到獨立檔案。
