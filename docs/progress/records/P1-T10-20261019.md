## 已知限制

1. **G1-2 是豁免通過**：本機網路在 04:13–10:43 中斷，原因不明（讀不到系統網路日誌）。依新定義成功率是 100%，但連續性不足由使用者豁免。日後如果要再驗證，用同一個指令重跑，並附在 `P1-stability.md`。
2. **中斷偵測可能誤判**：兩個網站剛好同時故障時，可能被當成全網中斷。報告會列出中斷時段，人工確認時要檢查。
3. **可重試的錯誤類型目前只有 `SourceUnavailableError`**：以錯誤類型的名稱判斷；以後新增可重試的 AdapterError 子類別時，要一起更新 `health._RETRYABLE_ERROR_TYPES`。
4. **一直連不上的來源不會被自動停用**：例如網站長期下線。這種情況會每輪產生死信，要從來源健康 API 或報告發現後人工處理。
5. **08:00 的 Facebook 排程**：launchd 準時啟動，但因為網路中斷（`ENOTFOUND`）失敗。排程機制本身已經驗證可以觸發，**能否寫檔**要等下一次正常的 08:00 執行才能確認。
6. **`--once` 不重試**：手動執行時遇到暫時性錯誤，會直接留下一筆失敗紀錄與死信。
