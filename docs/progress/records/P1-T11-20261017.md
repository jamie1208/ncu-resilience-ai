- 功能清單（ADR-0005）：
  - **`CwaOpenDataAdapter`**：以 `@registry.register("cwa_open_data")` 註冊，抓兩個資料集。
    - **W-C0033-001 天氣特報**：
      - 只取指定縣市（請求時帶 `locationName`，回應再篩一次）；
      - 每一項警特報為一個項目，external_id 為「資料集:縣市:類型等級:開始時間」，例如 `W-C0033-001:桃園市:大雨特報:2026-10-17T08:30:00+08:00`；
      - 標題為「桃園市大雨特報」，內文含有效時間（臺灣時間），連結到氣象署警特報總覽頁；
      - 發布時間為開始時間，原始資料沒有時區，視為臺灣時間。
    - **E-A0015-001 顯著有感地震報告**：
      - 取最近 `earthquake_limit` 筆（預設 20），**只保留震度分布包含桃園市的地震**（使用者決定）；
      - 桃園市的震度優先取它自己的條目，沒有時改取「最大震度 N 級地區」的分組條目；
      - external_id 為 `E-A0015-001:<地震編號>`，連結為官方地震詳情頁；
      - 內文含報告文字、桃園市最大震度、震央、規模與深度。
    - **出處**：依政府資料開放授權條款第 1 版，每個項目的內文最後都標示提供機關、年份、資料集名稱和授權條款網址。
    - **快照式資料**：不使用 cursor，每輪回傳目前全部項目，重複由冪等寫入處理。同樣的資料每輪產生的 id 和內文都相同（有測試）。
  - **授權碼**：
    - 只從環境變數 `CWA_API_KEY`（或 `NCU_CWA_API_KEY`）讀取，型別是 `SecretStr`，repr 不顯示；
    - 放在 HTTP **標頭** `Authorization`，不放網址。平台也接受 query 參數，但網址容易進日誌。實測過標頭方式可行；
    - 授權碼不會出現在網址、錯誤訊息和項目內容（有測試，真實 API 驗證也確認了）；
    - 沒有設定授權碼時，拋出不可重試的錯誤，也不會送出任何請求；
    - 設定檔不能寫授權碼：options 出現 `api_key` 會被拒絕。
  - **錯誤分類**：
    - 可重試：5xx、408、425、429、逾時、連線失敗；
    - 不可重試：401、403（授權碼無效）、其他 4xx、`success` 不是 true；
    - 版型改變：缺少 `records`、`location`、`Earthquake`，或警特報、地震的必要欄位缺漏。
  - **限速和 User-Agent**：沿用 P1-T03 的每網域限速器（間隔 ≥ 5 秒）和專案 User-Agent。這是 API，不檢查 robots.txt。

## 已知限制

- 警特報是「目前狀態」的快照，已過有效時間但仍列在回應中的警特報也會被收錄（例如這次實測的 10/15 陸上強風特報）。冪等寫入不會重複，但事件是否已結束要由後續分析依有效時間判斷。
- 地震只看最近 20 筆，兩次擷取之間（10 分鐘）發生超過 20 起顯著有感地震的機率極低。
- 只支援一個縣市（桃園市）；需要鄰近縣市時，要另外新增一個來源設定。
- 警特報的連結是氣象署總覽頁，不是單一警特報的頁面，因為 API 沒有提供個別頁面的網址。
- **ADR-0006 的風險**：一晚無法涵蓋週末、長時間運行和校方網站其他時段維護等情況；國際處每 6 小時擷取一次，一晚只有約 2 次，成功率的統計意義有限。
- 上線前要先執行 `make sources`，`cwa-alerts` 才會出現在 sources 表。
