## Migration

- 版本：`0024_series_actions_backfill`（down_revision `0023_series_analysis`）
- up：`report_cause_decisions` 加 `series_id`（FK event_series，ON DELETE SET NULL，索引）並依
  `event_reports.event_id → event_series_members` 回填；`response_actions` 中 event_id 不為 NULL 且 series_id 為
  NULL 的列，依 `event_series_members` 回填 series_id。
- down：事件層級措施（event_id 不為 NULL）的 series_id 改回 NULL；移除 `report_cause_decisions.series_id`。
  不刪任何列（測試驗證：4 筆措施、1 筆確認都保留，原本的 event_id／report_id 不變）。
