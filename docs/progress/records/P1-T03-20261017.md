- 功能清單：
  - **`RPageAdapter`**：以 `@registry.register("rpage")` 註冊。中央大學的 RPage 網站（校園公告、秘書室、國際處、教務處等）共用這個 Adapter，用 `list_url` 區分。
    - 同一網站有多個公告分類時改用 `list_urls`（例如教務處的總公告與課務組）：
      - 各列表合併並以文章編號去重；
      - 所有列表頁必須在同一網域，因為文章編號是站台內共用的流水號，cursor 才能共用；
      - 任何一個列表版型改變都會拋出 `LayoutChangedError`。
    - 列表頁：
      - 抓取 `.module-rcglist .mtitle a` 中符合 `/p/406-<站台>-<編號>,r<分類>.php` 的連結；
      - 只保留和列表頁同一網域的連結，並去除重複；
      - 已驗證表格（含／不含 `data-th`）與 listBS 三種版型；
      - 同一列的日期一併帶出。
    - 內頁：標題取 `h2.hdline`，發布日期取 `.ptinfoproperty_date`，內文取 `.meditor`。
    - 版型改變（`LayoutChangedError`）：
      - 列表頁找不到列表模組，或模組內沒有任何公告；
      - 內頁找不到 `.module-detail` 或缺標題。
  - **擷取原則**（來源盤點「共通擷取原則」）：
    - robots.txt：每個網域每個 Adapter 實例抓一次；
      - 404 視為全部允許；
      - 5xx 視為可重試錯誤，不會繼續抓列表；
      - 列表頁被禁止時拋出不可重試錯誤；
      - 內頁被禁止時略過該篇。
    - 同一網域請求間隔 ≥ 5 秒（`min_interval` 不能設低於 5），User-Agent 標示專案。
    - 單頁大小上限 2 MB；轉址到其他網域的內頁會略過。
  - **增量擷取**：
    - cursor 是已擷取的最大文章編號。每輪只抓編號更大的內頁，由舊到新最多 `max_items` 篇，避免 cursor 跳過未抓的文章，也大幅減少請求數。
    - 發布日期優先取內頁，沒有時用列表頁同一列的日期，都沒有時為 None。只有日期，所以視為台北時間 00:00，再轉成 UTC。
  - **錯誤分類**：
    - 可重試：5xx、408、425、429、逾時、連線失敗；
    - 不可重試：列表頁 4xx、頁面過大、cursor 格式錯誤；
    - 內頁 404：略過並計入 `last_skipped`。
  - **來源設定檔** `config/sources.yaml`：
    - 依 P1-T01 的決定，只放 Adapter 類型與 options；
    - 登記 4 個 RPage 來源：`ncu-announcements`、`ncu-sec`、`ncu-oia`、`ncu-aa`（教務處 495 總公告 + 498 課務組）。
  - **載入器** `app/ingestion/source_settings.py`：
    - `load_source_settings()`：safe_load 加上重複鍵檢查；拒絕未定義欄位、不合格式的來源代碼和不安全的 YAML 標籤。
    - `build_config()`：和資料庫中的授權狀態合併，產生 `SourceConfig`。
    - 測試會檢查設定檔中的來源都已在盤點核准、類型都已註冊、options 都通過各 Adapter 的驗證。

    - 限速器以網域排隊，同一網域同時只有一個請求。

## 已知限制

- 教務處只擷取總公告與課務組；招生組（目前 0 篇）、註冊組沒有登記，需要時在 `list_urls` 加網址即可。
- 不使用 RPage 的 AJAX 端點（`/app/index.php?Action=mobileloadmod`）：直接請求會回 404，也不是公開介面。
- 首次擷取（cursor 為 None）會從列表第一頁中**編號最小**的公告開始，可能包含置頂的舊文（例如秘書室的 2024 年公告），之後每輪逐步前進。只看列表第一頁，不回溯更舊的分頁。
- 公告被修改時，編號不變，不會重新擷取。內容版本偵測要等 P1-T06 再評估是否需要。
- 容器內還沒有掛載 `config/sources.yaml`（Docker 映像只含 backend）。P1-T07 啟用 worker 時要在 compose 加掛載，做法和 migrations 一樣。
- `access_policy`、`enabled` 和 `config/sources.yaml` 的合併由排程器（P1-T07）負責；這個任務只提供 `build_config()`。
- 只有日期，沒有時間，發布時間一律為台北時間 00:00。
- 其他非 RPage 的校方來源（總務處、計中、新聞網、圖書館、環安中心、生輔組）需要各自的解析器，不在本任務範圍。
