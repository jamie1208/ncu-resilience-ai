  - **`source_items.tags`**：`text[]`，`NOT NULL DEFAULT '{}'`。
    - 新文章寫入排序後的標籤；
    - 已存在的文章以 `ARRAY(SELECT DISTINCT t FROM unnest(old || new) ORDER BY t)` 取聯集，**標籤不會被移除**；
    - 只有標籤改變時不新增內容版本，計入 `unchanged`；
    - 同一批中的重複項目也會合併標籤。
  - **migration `0004_source_item_tags`**：依 ADR-0009，使用下一個可用編號；downgrade 會刪除欄位。

## 已知限制

1. **標籤只增不減**：來源移除某篇的分類時，資料庫仍保留舊標籤。這是刻意的設計，保留歷史紀錄。
2. **只有標籤改變不算「changed」**：`StoreResult` 與 `ingestion_runs.counts` 不會顯示標籤更新的數量。
3. **沒有建立索引**：`tags` 沒有 GIN 索引；之後需要依標籤查詢時再加。
4. **人工匯入格式還沒有 `tags`**：P1-T04 的格式白名單沒有 `tags` 欄位，Facebook 的社團名稱要在 P1-T13 擴充格式與文件時一起加。
5. **環安中心與圖書館沒有標籤**：列表上沒有分類資訊；環安中心內頁的「公告類型」目前沒有抽取。
6. **`categories` 屬性重複**：依決定 A 保留舊介面；之後可以另立任務，移除它並更新那兩個測試。
