- 功能清單：
  - **介面**（`base.py`）：
    - `LLMProvider.generate_structured(messages, json_schema, *, schema_name, model, timeout, max_output_tokens) -> LLMResult`，為 runtime_checkable 的 Protocol；
    - `Message`、`Usage`（輸入、輸出、快取輸入、推理 token）、`LLMResult`（provider、model、原始文字、usage、response_id、延遲）；
    - 錯誤階層：`LLMError` 帶 `retryable`、`status_code`、`retry_after`、`usage`；子類別有可重試的 `LLMUnavailableError`，以及不可重試的 `LLMAuthError`、`LLMRequestError`、`LLMRefusalError`、`LLMIncompleteError`；
    - Provider 只回傳原始文字。JSON 解析、schema 與業務驗證、重試、abstain 都由 P2-T04 Runner 處理。
  - **OpenAI**（`openai_provider.py`）：
    - 送 POST `/v1/responses`，格式為 `text.format = {type: json_schema, name, schema, strict: true}`，並帶 `max_output_tokens` 與 `store: false`；
    - 可選的 `reasoning.effort`，設定值為 low；
    - 讀取 `output[].content[]` 中的 output_text。refusal 拋出 `LLMRefusalError`；`status: incomplete` 拋出 `LLMIncompleteError`，並保留已花費的用量；
    - 錯誤分類：
      - 401、403 為 Auth；
      - 429 中的 insufficient_quota 為 Request，不可重試；其他 429，以及 408、409、5xx、逾時、連線失敗、回應不是 JSON，都可重試；
      - 其他 4xx 為 Request；
    - 保留 `retry-after`；
    - 錯誤訊息只保留 OpenAI 的錯誤說明（截斷為 300 字元）並移除金鑰；`repr` 不含金鑰。
  - **Fake**（`fake_provider.py`）：
    - 依序回傳預先準備的回應：物件會轉成 JSON 文字，字串原樣回傳（可模擬無效 JSON），`LLMError` 直接拋出；
    - 回應用完後再呼叫會拋出錯誤；
    - 記錄每次呼叫的參數（`calls`）；
    - `from_recorded()` 讀取 skill-standard §8 格式的錄製回應。
  - **費用**（`cost.py`）：
    - `call_cost` 依實際用量計費，快取的輸入用快取價格；
    - `estimate_input_tokens` 以 UTF-8 位元組數當 token 上限（每個 token 至少 1 位元組），加上 schema 與每則訊息的開銷；
    - `guard_call` 以最壞情況估算，超過每次上限就拋出 `CostLimitExceededError`，不送出；
    - `CostLedger` 累計每日費用，可以先 `check` 再 `record`。
  - **設定**（`config.py` ＋ `config/llm.yaml`）：
    - pydantic 驗證（`extra="forbid"`）；預設模型必須有價格；沒有價格的模型不允許呼叫；
    - `create_provider` 依 `provider: openai|fake` 建立 Provider；openai 沒有金鑰時拋出錯誤。

## 已知限制

1. **每日上限還不會自動生效**：`CostLedger` 只在單一行程內累計。P2-T04 要從 `ai_analysis_runs` 讀取當日已花費，才會真正限制每日費用。
2. **輸入 token 的估算偏高**：以 UTF-8 位元組數估算，中文約高估 2～3 倍（實測估算 US$0.0091，實際 US$0.00069），所以很長的輸入可能被誤擋。這是刻意選擇的安全上限；以後可以改用 tokenizer。
3. **不重試**：Provider 只分類錯誤，重試與退避由 P2-T04 處理。
4. **推理 token 算在輸出裡**：`max_output_tokens: 4000` 包含推理過程。推理強度改高的話，要一起調整輸出上限。
5. **價格要人工更新**：`pricing_checked_at` 是 2026-10-19。OpenAI 調價時要手動修改 `config/llm.yaml`。
6. **實測只有 1 筆**：還沒有驗證提示注入、拒答或長文的實際行為；這些在 P2-T05 評測與 P2-T14 測試中處理。
