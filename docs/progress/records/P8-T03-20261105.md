## 已知限制

- views 仍依「代表地點名稱」分組（沿用 0016 依名稱分組的做法）：兩個不同的代表地點同名時會被算在一起。再發生偵測依 id 分組，不受影響。
- views 只在 `refresh_views` 後更新，地點被判為別名或拆開後，要等下一次重新整理才會反映。
- P8-T02 補判（backfill）可能留下別名鏈：已經被當成目標的地點，之後自己又被判成別名。本任務沿著鏈找到最上層，但 resolver 本身沒有攤平。
