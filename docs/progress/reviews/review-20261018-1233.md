## 風險與偏離規格
1. **P1 → P2 的關鍵路徑卡在人工標記**：G1-5 要求 ≥ 100 筆人工確認的標記樣本，P2-T06（S01）又依賴 P1-T09。P1-T09 是「需你決定」的任務，分類法、真偽與同事件判準要你定案，標記也要你本人確認，這是目前最長的人工工時。證據：`docs/progress/phases.yaml` 中 P2-T06 `deps: [P2-T05, P1-T09]`；`data/labeled/` 目前沒有資料。
2. **migration 檔名與計畫不一致**：實際檔案是 `0002_audit_append_only.py`、`0003_ingestion_dead_letters.py`，但計畫中 P1-T07 寫 `0002_ingestion_dead_letters`、P2-T04 寫 `0003_ai_runs`、P3-T01 寫 `0004_users_roles`。Alembic 依 revision 串接，不影響運作，但照計畫建立檔案時會撞名。建議 P2-T04 起改用下一個可用編號。
3. **P1-T13 有外部前提**：需要 Claude in Chrome 已安裝、Chrome 登入 Facebook，且 `claude -p` 背景模式能連上擴充功能，目前都還沒驗證。帳號風險已記錄在來源盤點與 ADR-0008。
4. **個人使用的殘留尚未清理**（已排入任務，不是新問題）：`.env.example` 仍有 `AUTO_PUBLISH_ENABLED=false`（P3-T07）、`app/core/security.py` 仍有 `VISITOR`／`REPORTER` 角色與 `public:read`、`reports:create` 權限（P3-T01）、`frontend/src/public/` 仍在（P3-T05）。目前沒有公開端點：`main.py` 只掛載 health 與 admin router，admin 端點都要求權限，匿名請求會被拒絕。
