# ADR-0005：新增氣象署開放資料 Adapter（P1-T11）

- 狀態：已採納
- 日期：2026-10-17

## 背景

P1-T02 依計畫實作通用 RSS／Atom Adapter，但實作時發現沒有可用的 RSS 來源：

1. 12 個已核准來源中，11 個校方網站都沒有提供 RSS；校園公告頁面原始碼中的 RSS 選項被註解掉。
2. 唯一找到的公開 feed 是氣象署 RSS（`cwa-rss`）。但 feed 內附的使用聲明只授權私人、非商業用途呈現標題，並禁止「解析 RSS 相關資訊用以製作衍生產品」。本系統會解析內文產生事件分析，屬於禁止範圍。使用者決定**不核准**（2026-10-17）。
3. 已核准的 `cwa-alerts`（氣象資料開放平台 JSON API）適用政府資料開放授權條款第 1 版，允許改作與再利用，使用者也已取得授權碼。但計畫中沒有任何任務實作它。

閘門 G1-1 要求至少 3 個來源上線。目前只有 P1-T03 的 HTML Adapter 能讓來源上線，氣象類事件（颱風、豪雨、地震）也沒有資料來源。

## 決策

1. 新增任務 **P1-T11「氣象署開放資料 Adapter（cwa-alerts）」**，依賴 P1-T02（沿用 httpx2 執行期依賴與 User-Agent），列在 P1（使用者決定，2026-10-17）。
2. 計畫變更：
   - `docs/progress/phases.yaml` 新增任務並執行 `sync`；
   - 執行計畫加入任務定義；
   - 任務總數 61 → 62（同步更新 AGENTS.md、README.md、`docs/architecture/project-structure.md`）。
3. 範圍：
   - 資料集：天氣警特報 W-C0033-001、顯著有感地震報告 E-A0015-001，篩選桃園市。
   - 授權碼：只從環境變數 `CWA_API_KEY` 讀取（`SecretStr`），不得出現在日誌、錯誤訊息與 fixture。
   - fixture：依官方欄位格式製作；CI 不呼叫真實 API。
4. P1-T02 的 RSS Adapter 保留為通用元件。日後若有核准的 RSS 來源，只需要在 `config/sources.yaml` 登記即可。

## 考慮過的替代方案

- **把 P1-T02 改成 CWA Adapter**：RSS Adapter 已經完成，而且仍有通用價值；改寫既有任務的定義會讓驗收紀錄與計畫對不上。
- **核准 cwa-rss**：違反 feed 的使用聲明。
- **不新增任務，只靠校方 HTML 來源**：G1-1 在數量上仍可達成，但會缺少颱風、豪雨、地震等氣象類事件來源。

## 影響

- P1 任務數 10 → 11；P1-T10（七天穩定運行報告）應涵蓋 cwa-alerts。
- 開發與部署環境需要設定 `CWA_API_KEY`（`.env.example` 已有空值）。
