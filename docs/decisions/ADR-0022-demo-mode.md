# ADR-0022：示範模式（虛構資料、獨立環境）

- 狀態：已採納（使用者 2026-11-13 決定新增 P9-T01）
- 日期：2026-11-13
- 決定者：使用者本人（新增示範模式、示範站當場的新操作用真實模型）；隔離方式與實作細節由 AI 決定並記錄於此
- 不變：技術棧；公開規則引擎與硬性邊界；正式環境的資料、來源、排程與 tunnel；所有既有測試

## 背景

所有任務已完成，但真實資料量少且分散，無法一次展示所有功能，尤其韌性成績單（CRI）每個指標至少要 5 筆樣本，系列分析、趨勢解讀的突增、改善後再發生等情境在真實資料中不一定出現。使用者希望用假資料搭配流程完整展示所有功能，並能隨時拿掉假資料、回到真實環境。

## 決策

1. **獨立環境，不共用任何資料**：示範環境是另一個 compose project `ncu-demo`（`infra/docker/docker-compose.demo.yml` 疊在基礎檔上），有自己的 db、redis 容器與 volume，資料庫名稱 `ncu_resilience_demo`。「拿掉假資料」就是 `make demo-down` 或 `make demo-drop CONFIRM=yes`；真實環境不需要任何還原動作。不採用「在正式資料庫加 `is_demo` 標記、事後刪除」：要改所有資料表與查詢，刪除時也有誤刪正式資料的風險。
2. **種子的防呆寫在程式裡**：`app/demo/seed.py` 只在 `NCU_ENVIRONMENT=demo` 且資料庫名稱以 `_demo` 結尾時執行（`check_target`）。`Environment` 新增 `demo` 值。
3. **用流程產生資料**：種子以正式的寫入、管線（與正式 worker 相同的設定）、系列、措施、效益評估、What-if、趨勢解讀與公開同步函式建立資料，模型以 `app/demo/responder.py` 的 `DemoProvider` 代替。它依資料集（`app/demo/dataset.py`）與 Skill 的輸入組出輸出，照常經過 Skill Runner 的 schema、evidence_id、逐字原句與個資驗證。流程跑完後只回推時間欄位（事件建立時間、措施狀態時間、通知時間、擷取紀錄），讓 CRI 與趨勢有歷史分布；不直接寫入任何分析結果。
4. **示範站當場的新操作用真實模型**（使用者決定）：示範容器沿用 `.env` 的模型設定與費用上限。
5. **不擷取真實來源**：示範來源全部停用，只有內部的匿名回報收件匣保持啟用；worker 不掛載 `data/`。
6. **預設不對外**：示範站不接真實網站的 tunnel，只綁 127.0.0.1（api 8001、web 8089），db、redis 不開埠，不啟動 Prometheus、Grafana。虛構事件不會出現在真實網站上，也不會被誤認為真實事件。
7. **明確標示**：web 以 `VITE_DEMO=1` 建置，後台與公開站頂端顯示「示範資料」橫幅（`frontend/src/DemoBanner.tsx`，只用 contract 的共用 token，兩套設計都適用）。
8. **虛構內容的限制**：不含真實人名、店家名稱、電話或學號；疑似指控情境只寫「某家飲料店」。
9. **限時分享給組員（ADR-0015 的例外，使用者 2026-11-13 同意）**：`make demo-share` 以 Cloudflare Quick Tunnel 把**示範站**（公開站與 `/admin`）開放給組員，`make demo-unshare` 關閉。例外只限示範環境：
   - 通道屬於 compose project `ncu-demo`（`infra/docker/docker-compose.demo-share.yml`），轉送到示範站的 web；真實網站的通道（`infra/tunnel/`）與真實後台都不變，**真實後台仍不經通道對外**；
   - profile `share`，只有 `make demo-share` 會啟動；`restart: "no"`，電腦或 Docker 重開後自動關閉；
   - 組員共用示範帳號，操作只寫入示範資料庫，`make demo-seed` 可還原；
   - 分享期間示範站仍用 `.env` 的真實模型（決策 4），費用受 `config/llm.yaml` 每日上限約束；示範資料庫的花費與真實環境分開計算；
   - api 不信任轉送標頭：經通道的請求在限速上算同一個用戶端，匿名回報與登入的限速因此比較嚴；
   - 網址任何人取得都能開啟，只在示範期間開放，用完即關。

## 後果

- 示範資料的日期以播種日為準，過幾週後「近期突增」會變成過去，需要重新播種。
- 示範站上的新操作會產生模型費用；分享期間任何拿到網址的人都能觸發，上限為示範資料庫的每日費用上限。
- 分享期間示範後台的登入頁對外：登入失敗太多次會暫時鎖住示範帳號，`make demo-seed` 會重設並解鎖。
- 種子依賴正式服務函式的介面；那些函式改了簽名或驗證規則時，`tests/integration/test_demo_seed.py` 會失敗，需同步更新資料集或假模型。
