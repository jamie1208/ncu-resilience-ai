# 介面文案語氣指南：校園快報播報員

依據：ADR-0018 決策 3、ADR-0020 決策 5（P8-T10）。AI 產生內容的語氣另見 P8-T11：S02 的事件標題與摘要、S12 的系列名稱、系列說明與改善建議用播報員語氣（標題與系列名稱自 P8-T17 起，使用者 2026-11-11 決定）；S12 的規律、原因、查證方式維持平實。

**標準：示範頁第一版**（ADR-0021，使用者 2026-11-11 決定）：2026-11-05 示範頁（`https://claude.ai/artifact/8GiBG9iTzh8b9MK6xPgKaV`）第一版的快報文字就是語氣的標準。本指南與它衝突時，以第一版為準。

## 適用範圍

| 改成播報員語氣 | 維持原樣 |
| --- | --- |
| 公開網站的頁面說明、空狀態、成功訊息、入口卡片 | 文件、ADR、驗收紀錄（ADR-0018 3-3） |
| 後台介面的頁面說明、空狀態 | 程式註解、API 錯誤碼 |
| 通知範本 `backend/app/alerts/templates/factual.txt` | 未查證的中性提醒 `general_safety.txt`（屬「尚未查證」例外） |

導覽、按鈕、區塊標題、狀態標籤（已收到、處理中、已查證……）是功能性標示，保持簡短好認，不加播報語氣；它們也是無障礙名稱與測試的定位依據。

## 語氣規則

1. **像校園廣播台的主播在跟同學說話**：親切、有節奏，用「你」稱呼讀者，可以用「快報」「最新消息」「持續追蹤」「一次看」這類說法。
2. **先講重點**：一句話先說發生什麼或這頁能做什麼，再補細節；短句優先。
3. **有情緒、不誇大事實**：標題可以帶畫面與情緒，用「又傳」「驚傳」「借個書回來就消失了」這類播報說法，整則最多一個驚嘆號；但數字照實寫，不加證據沒有的形容（「大量」「不少」），不寫證據沒有的事。
4. **不用表情符號與顏文字**（含 emoji、☺、(^_^) 之類）；`frontend/src/tone.test.tsx` 與 `backend/tests/unit/alerts/test_template_tone.py` 會檢查。
5. **不改變事實與規則**：語氣只改說法，不新增承諾、不暗示未查證的事已經發生，也不讓推測聽起來像結論。
6. **白話**（ADR-0020 決策 5）：避免「構面」「調適」「覆蓋率」等術語出現在公開頁的主要說明；需要時放在次要文字。

## AI 快報的寫法（S02、S12，取自示範頁第一版）

- **標題**：20 字左右，有畫面、帶情緒，先講發生什麼。
- **摘要**：先講經過（誰回報、看到什麼），再補現在的狀況，最後給一句實用提醒（「停車記得上兩道鎖、盡量停在燈下」）。
- **件數不寫**：「本月第 3 起」這類件數由程式顯示（「XX 系列 · 第 N 起」），AI 不寫。
- **安全底線不變**：不寫人名、店名與個資；社群說法寫成「有同學反映」「有同學一早回報」；不推測原因、不評論責任。

| 欄位 | 第一版範例 |
| --- | --- |
| 標題 | 宿舍區車棚又傳失竊！藍色腳踏車昨晚不見了 |
| 標題 | 後門停車場驚傳「照後鏡小偷」 |
| 標題 | 中正圖前的腳踏車，借個書回來就消失了 |
| 標題 | 總圖三樓天花板又滴水，靠窗座位先暫停開放 |
| 標題 | 中大路早上大塞車，校園公車晚到 15 分鐘 |
| 摘要 | 有同學一早回報，停在宿舍區車棚的藍色腳踏車整台不見，只剩被剪斷的鋼索鎖。停車記得上兩道鎖、盡量停在燈下。 |
| 摘要 | 下課回到後門機車停車場，有同學發現兩支照後鏡被拆走。貴重配件建議先收起來。 |
| 摘要 | 總圖書館公告：三樓靠窗區天花板滲水，部分座位暫停使用，已放置接水桶並通知修繕。想找安靜座位可以先去四樓。 |
| 摘要 | 工程一館 9 點到 12 點停電檢修，電梯與電腦教室暫停使用。正在跑實驗或寫報告的同學記得提早存檔。 |
| 系列名稱 | 腳踏車失竊（系列可能跨地點，名稱不寫地點；第一版的「總圖漏水」改寫成「天花板滴水」） |
| 改善建議 | 上兩道鎖，其中一道鎖在車架、鎖在固定物上／晚上盡量停在有燈、有人經過的位置／駐警隊在晚上 10 點後增加車棚巡邏 |

## 例外：一律平實

以下內容不加播報語氣、不加修飾，原句改動需要明確理由：

- **緊急資訊**：110／119、校安中心、火災、地震避難，以及「本站不是緊急通報管道」「這裡不是報案管道」。
- **查證標籤與說明**：「尚未查證」「推測，尚未查證」「已確認」，以及「尚未查證：這是 AI 依公開來源整理的摘要……」這類說明句。
- **非官方聲明、公開規則、隱私說明**：關於本站的公開規則、匿名回報的「原文不會公開」「不記錄 IP」「請勿填寫姓名、電話」。
- **具體限制**：限流次數、字數、上限、「變少不一定是措施的功勞」、「任一邊少於 5 起就不比較」。
- **未查證的中性提醒範本** `general_safety.txt`。

## 校園韌性成績單的四個問題（ADR-0020 決策 5）

| 構面 | 問題 |
| --- | --- |
| 發現 detection | 出事後，多快有人知道？ |
| 回應 response | 知道之後，多快開始處理？ |
| 恢復 recovery | 開始處理後，多久恢復正常？ |
| 調適 adaptation | 同樣的事，有沒有一再發生？ |

分數規則不變（P6-T05）；頁面明寫「幾天算好是本專題自己訂的目標，不是學校的官方標準」。
