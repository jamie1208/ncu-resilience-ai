# 地點判斷規則

## 三種關係

| 關係 | 意思 | 例子 |
| --- | --- | --- |
| `alias_of` | 同一個地方的不同寫法 | 工五 → 工程五館；總圖 → 總圖書館；舊圖 → 中正圖書館；綜教館 → 綜合教學館；本校大禮堂 → 大禮堂 |
| `inside_of` | 位在某個較大的地方裡面 | 工程五館二樓 → 工程五館；男九舍 → 宿舍區；總圖三樓自習區 → 總圖書館 |
| `new` | 和所有候選都不是同一處、也不在其中之內 | 新地點「游藝館」，候選只有工程五館、總圖書館 |

`alias_of` 與 `inside_of` 的方向：新名稱是較小、較具體的地方，`target_id` 是較大的那個。新名稱比候選大（例如新名稱「宿舍區」、候選「男九舍」）→ `new`，不是反過來的包含。

## 常見簡稱（S02 的標準名稱與寫法）

- 工程一館～工程五館 ← 工一～工五
- 科學一館～科學五館 ← 科一～科五
- 總圖書館 ← 總圖
- 中正圖書館 ← 舊圖
- 管理學院 ← 管院
- 綜合教學館 ← 綜教館
- 宿舍：男一舍～男十四舍、女一舍～女十四舍、國際學生宿舍等都在「宿舍區」之內（候選中有宿舍區時）

## 容易出錯的情況

- **同字不同地**：「圖書館」可能是總圖書館、國鼎圖書館或中正圖書館；「一館」可能是工程一館或科學一館；「後門」與「後門停車場」是不同層級（停車場在後門一帶 → `inside_of`，候選有「後門」時）。證據沒有寫清楚指哪一個 → abstain（`insufficient_evidence`），不要猜。
- **同一層級的兩棟**：工程一館與工程二館、男九舍與男十舍是不同地方，彼此不是別名，也沒有包含關係 → `new`。
- **周邊地標**：後門、宵夜街、雙連坡、中大路是彼此獨立的地方，沒有包含關係（雙連坡不在中大路之內）→ 互相比較時是 `new`；同一條路的不同路口仍算同一條路（`alias_of`）。
- **特殊值**：「全校」「校外」「不明」不會送來判斷；若證據只寫「校內」「學校」，屬於泛稱 → abstain（`invalid_location`）。

## 信心

- 原文寫出全名或括號註明簡稱：0.9 以上。
- 只靠常見簡稱對照：0.8 左右。
- 需要推測：0.6 以下，並優先選 `new`。
