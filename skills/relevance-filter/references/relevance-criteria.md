# 校園相關性判斷準則

依據：`data/labeling/guidelines.md` 第 1 節（人工標記與本 Skill 使用同一套準則）。

## 相關（is_campus_relevant = true）

符合任一項：

1. **影響中央大學的師生、建築或服務**：停水停電、網路或系統中斷、停課調課、考試、宿舍、圖書館、校內交通。
2. **發生在校園或周邊生活圈**：校內各館舍、宿舍；中大路、宵夜街、後門一帶。
3. **中央大學的單位發布的公告**：各處室、系所、中心、實驗室的一般公告、活動宣傳、學術新聞、獎學金，也算相關（不論是不是事件）。
4. **中央大學各單位、系所、實驗室的徵才與徵求受試者**。
5. **桃園市的天氣與災害特報**，以及桃園市的停班停課公告（會影響到校）。
6. **中央大學師生在校內的親身經歷、遺失物、協尋**。
7. **中央大學與其他單位合辦**、在中央大學舉辦的活動。

## 不相關（is_campus_relevant = false）

1. **其他學校的消息**，沒有提到對中央大學的影響。
   - 注意名稱相近的學校：「中央警察大學」「中原大學」不是中央大學。
2. **全國性或其他縣市的新聞、政策、天氣**，沒有明確提到中央大學或桃園市。
   - 例：教育部對全國大專校院的一般政策、花蓮縣的大雨特報。
3. **校外公司或個人的徵才、廣告、補習班招生、二手買賣**，即使貼在中央大學的社群。
4. **離校園較遠的中壢、桃園其他地點的消息**（例如中壢火車站、中壢夜市），沒有影響中央大學。

## 校內地點與來源

- `facebook` 來源是中央大學的學生社團（NCU 社團），貼文提到下列校內地點時，視為發生在中央大學，即使沒有寫出校名：
  - 宿舍：以編號稱呼的宿舍，例如「男九舍」「女二舍」「12 舍」；
  - 館舍：工程一館～工程五館（工一～工五）、科學一館～科學五館（科一～科五）、文二館、鴻經館、管理學院（管院）、綜合教學館（綜教館）、國鼎圖書館、總圖書館、中正圖書館（舊圖）、大禮堂、游藝館、依仁堂、松苑、行政大樓；
  - 校內地標：百花川、小木屋、管院天橋、後門、宵夜街、中大路、雙連坡。
  - 清單只列出公告與貼文中出現過的地點，不是完整清單；其他明顯是校內建築的名稱也一樣處理。
- 官方來源（`ncu-*`）都是中央大學的單位，公告內容一律視為與本校相關（除非公告明確是轉知其他單位、與本校無關的事）。

## 判斷時

- 看內容本身，不是看貼在哪裡：貼在中大社團的校外廣告仍然不相關。
- 標題與內文都要看；轉貼的官方公告，依公告內容判斷。
- 內容同時提到中央大學與其他地方時，只要有實際影響中央大學師生或校園就算相關。

## 證據不足（abstain）

- 內文已刪除、只剩標點或表情符號；
- 只有「詳見附件」「如連結」「同上」等文字，標題也無法判斷。
