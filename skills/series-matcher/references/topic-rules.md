# 同主題判斷規則

## 什麼是同一個主題

**同主題＝同一種問題**：同一種現象，發生在同一類對象上。系列用來觀察「這種問題多常發生、改善後有沒有變少」，所以只看問題本身，不看在哪裡、什麼時候、誰發布。

| 看 | 不看 |
| --- | --- |
| 現象（停電、漏水、失竊、拖吊、腹瀉…） | 地點（工五停電與宿舍停電是同主題） |
| 對象的種類（機車、筆電、電梯、飲水機…） | 時間（隔了半年再發生仍是同主題） |
| | 發布者、來源、查證狀態、嚴重程度 |
| | 直接原因（施工造成的停電與跳電都是停電） |

同一件事的多篇報導由 S04 合成同一個事件；本 Skill 只判斷**不同事件**是不是同一種問題。

## 各類別的主題切分

| 類別 | 同主題的例子 | 不同主題的例子 |
| --- | --- | --- |
| facility | 停電、跳電、電力中斷、限電；停水、水壓不足、無預警停水；網路斷線、Wi-Fi 連不上；電梯故障、電梯困人 | 停電 vs 停水；電梯故障 vs 飲水機故障；漏水 vs 空調故障；施工噪音 vs 施工停電（後者是停電） |
| weather | 颱風（停課、警報）；豪雨、淹水、積水；地震 | 颱風 vs 地震；高溫 vs 寒流 |
| security | 機車失竊、自行車失竊（車輛失竊）；宿舍、教室、圖書館的個人財物失竊（錢包、筆電、手機）；可疑人士、跟蹤、騷擾；偷拍 | 車輛失竊 vs 個人財物失竊；詐騙 vs 失竊；偷拍 vs 失竊 |
| traffic | 車禍（不同路口都算）；違規停車取締、拖吊；接駁車延誤、改線 | 車禍 vs 拖吊；道路封閉 vs 接駁車異動 |
| health | 食物中毒、吃完腹瀉（食安）；流感群聚；登革熱 | 食安 vs 流感；流感 vs 登革熱 |
| fire | 火警、冒煙、警報響起（含誤報）；瓦斯外洩 | 火警 vs 瓦斯外洩；火警 vs 人員受傷 |
| academic | 停課；考試時間或方式異動 | 停課 vs 考試異動 |
| infosec | 釣魚（信件、簡訊、假登入頁）；帳號盜用；惡意程式；個資外洩 | 釣魚 vs 個資外洩 |

表中沒有的問題，依「同一種現象＋同一類對象」自行判斷。

## 容易出錯的情況

- **同地點不同問題**：「工五停電」與「工五漏水」是不同主題，不能因為地點一樣就判同主題。
- **同字不同事**：「電梯故障」與「電梯按鈕標示更新」都有電梯，前者是電梯不能用、後者不是；「停水」與「飲水機沒水」，前者是供水中斷、後者是設備問題。要看現象，不是看有沒有同一個詞。
- **預告與突發**：「電梯維護停機公告」與「電梯故障」都是電梯不能用，算同主題；「停電檢修公告」與「跳電」都是停電，算同主題。
- **系列名稱太寬**：候選系列的名稱只是第一起事件的標題，要看系列裡的事件內容判斷，不要只比名稱。
- **好幾個候選都像**：選最具體、最貼近的那一個；真的分不出來時選和最近幾起事件最像的那一個。
- **有疑問時選不同主題**：把不同的問題放進同一系列，會讓公開系列頁的頻率算錯；漏掉一次歸組只是多一個 1 件的系列，使用者看得到。

## 信心

- 現象與對象都明確相同：0.9 以上。
- 現象相同、對象只能從上下文推斷：0.7 左右。
- 需要推測：0.6 以下，並優先選不同主題（`same_topic: false`）。
