# 事件分類法（S03）

與人工標記使用同一套 9 類（`data/labeling/guidelines.md` 第 2 節；使用者 2026-10-18 決定，ADR-0009）。兩份文件要一起修改。

## 類別

| 代碼 | 類別 | 包含 | 不包含 |
| --- | --- | --- | --- |
| `facility` | 設施與營運 | 停水停電、施工、網路或系統中斷、系統維護停機、電梯或空調故障、漏水、場館閉館 | 施工造成的道路封閉 → `traffic` |
| `weather` | 天然災害與氣象 | 颱風、豪雨、地震、高溫、寒流、低溫、強風、淹水 | 颱風造成的停課公告 → 仍是 `weather` |
| `security` | 治安與財物 | 失竊、詐騙（電話、面交、假冒單位要求匯款）、可疑人士、騷擾、偷拍 | 釣魚信、假冒網站或簡訊騙取帳號密碼、帳號盜用 → `infosec` |
| `traffic` | 交通與停車 | 車禍、道路封閉、拖吊、違規停車取締、接駁車異動、交通管制 | |
| `health` | 健康與食安 | 食物中毒、腹瀉群聚、傳染病（流感、登革熱、疥瘡）、實驗室化學品外洩 | |
| `fire` | 火災與緊急意外 | 火警、冒煙、瓦斯外洩、爆炸、人員受傷或溺水等緊急意外 | 交通事故 → `traffic`；疾病 → `health` |
| `academic` | 教務與課務異動 | 非天災原因的停課、補課、調課、考試時間或方式異動 | 選課、獎學金、招生等例行公告 → `none` |
| `infosec` | 資訊安全 | 帳號盜用、釣魚信、假冒登入頁面或簡訊、惡意程式、個資外洩 | 系統維護停機 → `facility` |
| `none` | 非事件 | 一般公告、活動宣傳、學術新聞、徵才、徵求受試者、社團招生、遺失物協尋、閒聊、心得 | |

## 判斷規則

1. **看事件本身是什麼，不看誰發布的**。教務處發布的颱風停課是 `weather`；計算機中心發布的系統維護是 `facility`。
2. **同時符合多類時，依「原因」歸類**，結果放進 `tags`：
   - 颱風、豪雨造成停電或淹水 → `weather`，tags 寫「停電」「淹水」；
   - 實驗室起火造成停電 → `fire`，tags 寫「停電」；
   - 施工造成道路封閉 → `traffic`，tags 寫「施工」；
   - 教師生病而停課 → `academic`（事件是課務異動，不是疫情）。
3. **詐騙看手法**：以電話、面交、假冒單位要求匯款或操作 ATM → `security`；以信件、簡訊、假網站騙取帳號密碼 → `infosec`。
4. **場館閉館、暫停服務**屬於營運異動 → `facility`；只是開放時間的例行公告（例如寒假開館時間）→ `none`。
5. **是不是事件**：有具體發生或預定發生的事，會影響到人，就是事件。只有一個人遇到的失竊、身體不適也是事件。

## 建議標籤

標籤用來記下類別以外的細節，每篇 0～5 個，每個 20 字以內。優先使用下表的詞；表中沒有合適的詞時，才自己寫簡短的名詞。

| 類別 | 建議標籤 |
| --- | --- |
| facility | 停電、停水、施工、網路中斷、系統維護、電梯故障、空調故障、漏水、閉館 |
| weather | 颱風、豪雨、地震、強風、高溫、低溫、淹水、停課 |
| security | 失竊、詐騙、可疑人士、騷擾、偷拍 |
| traffic | 車禍、道路封閉、拖吊、接駁車、交通管制、施工 |
| health | 食物中毒、腹瀉、傳染病、化學品外洩 |
| fire | 火警、冒煙、瓦斯外洩、爆炸、受傷、溺水、停電 |
| academic | 停課、補課、調課、考試異動、線上授課 |
| infosec | 釣魚信、帳號盜用、惡意程式、個資外洩、假冒簡訊 |
| none | 學術新聞、活動、徵才、受試者招募、社團、獎學金、選課、遺失物 |

- 標籤裡**不寫**人名、店名、系級、電話、email、帳號。
- 標籤記下的是文章內容，不是查證結果：不要寫「已核實」「謠言」等判斷。
