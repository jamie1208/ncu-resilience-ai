# 時間與地點的抽取規則

## 地點

`location` 一律寫成下列的標準名稱或特殊值，方便後續關聯同一地點的事件（S04）。

### 特殊值

| 值 | 何時使用 |
| --- | --- |
| `全校` | 影響整個校園：全校停課、全校性的系統或網路中斷（Portal、Email、VPN）、桃園市的天氣特報與地震 |
| `校外` | 發生在校園與周邊生活圈以外的地方，例如中壢火車站、其他縣市 |
| `不明` | 是事件，但沒有寫出地點，也無法從內容推斷；或只有泛稱（宿舍、教室、餐廳、校園、系館），沒有指出是哪一棟 |

### 校內地點（標準名稱 ← 常見寫法）

- 工程一館～工程五館 ← 工一～工五
- 科學一館～科學五館 ← 科一～科五
- 文二館
- 鴻經館
- 管理學院 ← 管院
- 綜合教學館 ← 綜教館
- 國鼎圖書館
- 總圖書館 ← 總圖
- 中正圖書館 ← 舊圖
- 大禮堂
- 游藝館
- 依仁堂
- 松苑
- 行政大樓
- 宿舍：寫成「男X舍」「女X舍」「X舍」，X 用國字，例如「男九舍」「女二舍」「十二舍」（← 12舍、男9舍）
- 校內地標與周邊：百花川、小木屋、管院天橋、後門、宵夜街、中大路、雙連坡
  - 周邊生活圈（後門、宵夜街、中大路、雙連坡）的店家與路段，地點填該地標（例如「後門那間早餐店」→「後門」），不填「校外」。

清單只列出公告與貼文中出現過的地點。不在清單上的校內地點，照原文的名稱寫（去掉「本校」「中大」等前綴）。

### 有多個地點時

- 取事件**主要發生**的地點；一樣重要時，取原文第一個出現的地點。
- 道路路口（例如「中大路與雙連坡路口」）取第一個出現的路名。
- 同時列出多棟建築（例如「工程一館、工程二館停電」）取第一個。

## 時間

- 一律使用台北時間。日期寫 `YYYY-MM-DD`，時間寫 `HH:MM`（24 小時制）。
- 民國年加 1911 換成西元年（115 年 → 2026 年）。
- 只寫月日時（例如「10/25」），年份取發布時間的年份；如果因此早於發布時間超過兩個月，改用下一年。
- 相對時間以發布時間（台北時間）為基準：
  - 「今天」「今晚」「剛剛」→ 發布當天；「昨天」「昨晚」→ 前一天；「明天」→ 後一天；
  - 「本週X」→ 發布時間所在那週（週一到週日）的星期X；「下週X」→ 下一週的星期X。
- 只有開始、沒有結束時，結束日期與時間為 null；同一天內的時段（例如「02:00–06:00」）結束日期與開始日期相同。
- 沒有寫出時間，也無法推斷時，四個時間欄位都是 null。
