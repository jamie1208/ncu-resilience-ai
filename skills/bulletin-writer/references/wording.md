# 用語對照

把原文的公告或轉述用語換成口語。只是提示，照 SKILL.md 的範例寫就好。

| 原文常見 | 改成 |
| --- | --- |
| 期間暫停服務、暫停使用 | 不能用、連不上、停一小時 |
| 進行停電檢修、進行設備更新 | 停電檢修、設備更新 |
| 配合台電檢修 | 台電來檢修 |
| 請各位師生預先完成存檔作業 | 記得先存檔 |
| 請用路人注意安全 | 經過記得放慢、小心 |
| 造成不便敬請見諒 | （不寫） |
| 發文者表示、網友指出、有學生反映 | 直接講事情：「一早就整台不見」「傳出有東西被偷」 |
| 車主、師生、學生 | 同學、大家，或直接省略 |

時間寫法：

- 排定的事寫日期與時段：「11/3（二）上午 9 點到 12 點」「10/28 晚上 9 點到 10 點」。
- 已經發生的事不寫日期，也不要把「剛剛」「今天」和日期疊在一起（不寫「剛剛晚上約 11/9 晚上 7 點」）。
