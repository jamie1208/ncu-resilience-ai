# 措施的類型、時程與優先級（S08）

## 類型（kind）

| kind | 用途 | 範例 |
| --- | --- | --- |
| `respond` | 降低眼前的影響、恢復服務 | 學生避開現場、改到其他地點上課；校方公告恢復時間、派員搶修 |
| `investigate` | 查證待查證的原因或原因不明的事件 | 請總務處確認跳電原因；請衛保組調查患者共同飲食 |
| `prevent` | 防止再發生 | 汰換老舊設備、定期檢查、修訂作業流程 |

## 依原因的 basis 決定能提什麼

| basis | 必須 | 可以 | 不可以 |
| --- | --- | --- | --- |
| `confirmed` | 至少一項 respond 或 prevent | 直接寫修復與預防措施 | — |
| `hypothesized` | 至少一項 investigate | 寫成「若查證屬實，…」的 prevent | 把原因寫成已確定、建議懲處或公開特定對象 |
| 沒有原因（causes 為空） | 一項 investigate（cause_id 為 null） | 一般 respond | 自行假設原因 |

## 時程（horizon）

- `short`：立即到一週內（應變、查證、臨時措施）
- `mid`：一學期內（修繕、流程調整）
- `long`：一學期以上（汰換設備、建置系統、制度）

## 優先級（priority）

- `high`：涉及人身安全、風險分級 high／critical，或影響範圍大的立即措施
- `medium`：防止再發、查證
- `low`：長期改善、錦上添花

## 建議負責單位

| 類別 | 常見單位 |
| --- | --- |
| 設施（水電、空調、建築） | 總務處（營繕組、事務組） |
| 實驗室、化學品、火警 | 環安中心 |
| 宿舍、學生生活 | 學務處（生活輔導組、住宿服務組） |
| 健康、傳染病、食物中毒 | 學務處衛生保健組 |
| 校園安全、治安 | 軍訓室（校安中心）、駐衛警 |
| 網路、資安 | 電算中心 |
| 圖書館服務 | 圖書館 |
| 停課、考試 | 教務處 |

只寫單位，不寫人名或職稱加姓名。
